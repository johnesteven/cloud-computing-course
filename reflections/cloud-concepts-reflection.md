# Cloud Concepts and Version Control Reflection

 1. Cloud Services I Use

In my daily digital routine, I regularly interact with cloud computing applications for communication, social networking, and entertainment. Three cloud services I use daily are:
- Messenger
- Facebook
- TikTok
  
2. Identify the Models

- Messenger
  - Service Model: Software as a Service (SaaS)
  - Deployment Model: Public Cloud
  - Explanation: Messenger is an end-user communication tool accessed via mobile apps or browsers. Users interact directly with the messaging software without managing underlying application servers, databases, or networking infrastructure. It operates on Meta's public cloud infrastructure to serve millions of global users.

- Facebook
  - Service Model: Software as a Service (SaaS)
  - Deployment Model: Public Cloud
  - Explanation: Facebook delivers social networking features, media sharing, and content feeds directly to end users over the internet. The entire platform infrastructure is fully managed by Meta, providing shared public access without requiring users to maintain system hardware or software execution environments.

- TikTok
  - Service Model: Software as a Service (SaaS)
  - Deployment Model: Public Cloud
  - Explanation: TikTok provides a complete video hosting and streaming application. Users consume, upload, and edit content while algorithms process media streams in real time. The underlying cloud storage, compute power, and content delivery networks (CDNs) are hosted entirely on public cloud infrastructure.

 3. Git & GitHub for Cloud Projects

Version control is critical when working with cloud infrastructure because modern cloud systems are managed using Infrastructure as Code (IaC). Defining servers, databases, and network policies in code scripts makes version control essential for maintainability.

GitHub enables teams to:
- Collaborate: Engineers can work on isolated feature branches simultaneously, using Pull Requests and code reviews to verify configuration changes before merging them into live cloud environments.
- Track Changes: Every infrastructure update is logged with accurate timestamps, author details, and commit histories, maintaining a clear audit trail for security and troubleshooting.
- Prevent Errors: If an infrastructure misconfiguration causes downtime or security risks, GitHub allows teams to quickly roll back to a previously stable commit, instantly restoring system stability.
